# Creating an Emoji Memory Game Using JavaScript

Project developed during the Potência Tech iFood Game Development Bootcamp, under the guidance of expert [Felipe Aguiar](https://github.com/felipeAguiarCode "Felipe Aguiar").

In this project challenge, we will use HTML, CSS, and JavaScript to build a memory game featuring the Windows emoji keyboard; we will delve extensively into CSS styling and JavaScript events.

## Features

- **Responsive Design:** Adapts cleanly across desktop, tablet, and smartphone screens using CSS Grid and fluid typography (`clamp()`).
- **Accessibility (a11y):** Uses semantic HTML tags (`<header>`, `<main>`, `<section>`), keyboard-navigable `<button>` elements for cards, visible focus rings, and `aria-live` status announcements.
- **Theme Switcher:** Supports **Dark Mode** (default) and **Light Mode** with sun/moon toggle icons.
- **Multilingual Support:** Instant switching between **English (`EN-US`, default)**, **Portuguese (`PT-BR`)**, and **Spanish (`ES-ES`)**.

## Tecnologies used

- **HTML5**: Semantic HTML structure
- **CSS3**: Responsive styling, animations, and theme variables
- **Vanilla JavaScript**: Game logic, shuffle algorithm, and i18n handling

## How to Run

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser, or serve it using a local development server (such as VS Code Live Server).

See [original repository](https://github.com/digitalinnovationone/js-emoji-memory-game).
